# Studia---Predicting-AI

An application that helps you study with 4 different functionalities by using Machine Learning (Scikit-Learn). The programm is made by Python 3.

## Functionalities
* Predicts score based on hours studied
* Calculate hours needed for a desired score
* Create a Graph to understand the ratio of score/hour
* Create a Study Alarm
* Saving your predictions

## Needed Libraries
* **[scikit-learn](https://scikit-learn.org/)** Used for the Machine Learning algorithm
* **[numpy](https://numpy.org/)** Used for Graphs and array manipulation
* **[matplotlib](https://matplotlib.org/)** Used for creating the visual of the graphs
* **[rich](https://rich.readthedocs.io/)** Used for the styling the terminal with : bars, spinners, progress bars, etc.
* **[questionary](https://pypi.org/project/questionary/)** Used for the interactive menu selector.
